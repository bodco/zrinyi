# Zrínyi gyakorló

Тренажер для підготовки до математичного конкурсу імені Ілони Зріні (2-8 клас), угорською та українською. Діти обирають клас і розвʼязують задачі. Наприкінці бачать результат і проходять покроковий розбір помилок з Арчі, джек-рассел-терʼєром.

Адреса: https://zrinyi.bodco.pm

## Структура
- `index.html`, `css/app.css`, `js/` (`app.js` екрани, `logic.js` вибір задач, бали, серія, `rewards.js` кісточки й шафа, `store.js` localStorage, `i18n.js` тексти HU/UA, `mascot.js` Арчі та його одяг) - статичний сайт без збірки.
- `data/g2.json` ... `data/g8.json` - задачі за класами.
- `sw.js` - офлайн-кеш. Щоб змусити клієнтів оновитися, підніми версію кешу в цьому файлі.
- Прогрес зберігається лише в localStorage браузера (ключ `zrinyi.v1`). На сторінці прогресу його можна експортувати й імпортувати.

## Формат задачі
```json
{"id":"g5-r2014-07","grade":5,"source":{"type":"real","year":2014,"round":"megyei","no":7},
 "topic":"logic","difficulty":2,"q":{"hu":"...","uk":"..."},"figure":"<svg>...</svg>",
 "options":{"A":"6","B":"9","C":{"hu":"kedd","uk":"вівторок"},"D":"12","E":"16"},"answer":"C",
 "hint":{"hu":"...","uk":"..."},"hints":{"hu":["...","...","..."],"uk":["...","...","..."]},"steps":{"hu":["..."],"uk":["..."]},
 "why":{"A":{"hu":"...","uk":"..."},"B":{},"D":{},"E":{}},"tip":{"hu":"...","uk":"..."}}
```
`level`: необовʼязкове, `"challenge"` для особливо складних задач.
`topic`: numbers, operations, measures, time, geometry, logic, combinatorics, patterns, word. `difficulty`: 1-3. `why` має пояснення для кожного неправильного варіанта.

Реальні задачі взято з бланків конкурсу Zrínyi Ilona Matematikaverseny минулих років (MATEGYE Alapítvány). Решту задач написано для цього сайту.

## Підказки (`hints`)
`hints` має по 3-5 рядків для кожної мови, від найлегшого натяку до детального, але відповідь ніколи не розкривається. Кнопка "Segítség / Підказка" відкриває рівні по одному (бульбашки "1/4", "2/4" ...). Підказки є в тренуванні (швидкому і повному) та в роботі над помилками, у пробному конкурсі їх немає. Якщо `hints` немає, у роботі над помилками показується лише одна `hint`. У сесії рівні зберігаються в `hints` (макс. відкритий рівень), у `problemStats` це `hintsUsed` і `hintOk` (правильно з підказкою); у результатах біля таких задач значок "💡 N".

## Задачі "challenge" і режим "Виклик"
Задачі з `"level":"challenge"` при рівні "Легше" не потрапляють у швидке, повне тренування і пробний конкурс (при рівні "Як на конкурсі" можуть потрапити). Окремий режим "Kihívás / Виклик" показує до 5 challenge-задач плюс найважчі задачі складності 3, разом 8, без таймера). Режим зʼявляється, лише якщо в класі є такі задачі. Ці сесії не впливають на відсоток правильних.

## READY_GRADES
У `js/logic.js` константа `READY_GRADES = [2, 5]` визначає, які класи вважаються готовими. Решта плиток на стартовому екрані отримують позначку "Hamarosan / Незабаром", але лишаються клікабельними і ведуть на екран "coming soon" (він показується, коли файл даних порожній). Коли додаєш новий клас, заповни `data/gN.json` і додай номер у `READY_GRADES`. Після змін у файлах підніми `VERSION` у `sw.js` (зараз `zrinyi-v6`).

## Режими
- Швидке тренування: 10 задач.
- Повне тренування: стільки задач, як на бланку (`mockN`: 25, у 7-8 класі 30), від легких до складних, без таймера, з підказками. Цілі за складністю: "Як на конкурсі" 8/10/7, "Легше" для 2-3 класу 11/10/4, для інших 9/10/6 (для 30 задач пропорційно). Його можна перервати й продовжити (`active`).
- Пробний конкурс, Виклик, Робота над помилками, Мій прогрес, Шафа Арчі. Окремого режиму "Теми" більше немає, знання за темами видно на сторінці прогресу.

## Нагороди (`rw` у кожному класі)
`rw = {bones, earned, goal, days, goalDays, freezes, frozen, chests, owned, outfit, lvlSeen, mig}`. Кісточки: +2 за правильну відповідь, +1 якщо без підказок, бонус за завершене тренування (швидке 5, повне 15, пробний 20, виклик 8, якщо відповідь дано хоча б на половину), +3 за помилку, виправлену самостійно (+1 з підказками). Нічого не віднімається. `bones` витрачаються в шафі, рівень рахується з `earned` (`LEVEL_AT` у `logic.js`). Мета дня 30/50/80 (типово 30 для 2-3 класу, 50 для інших). Ковдрочка (`freezes`, максимум 2) автоматично закриває пропущений день серії; дається за кожні 7 днів поспіль або купується за 60. Скриня тижня (+40) за 5 активних днів за тиждень. Старі збереження без `rw` один раз отримують 10 кісточок за кожне завершене тренування. Експорт (версія 2) містить `rw`.

## Вибір задач
Швидке тренування: 10 задач, цілі за складністю для класів до 3 включно 5/4/1, для решти 4/4/2, порядок строго від легших до важчих (складність, потім `source.no` для реальних, потім випадково). Перевага ще не баченим задачам, без повторів з останніх сесій, реальні та згенеровані задачі приблизно порівну.

## Локальний запуск
`python3 -m http.server` у цій папці, потім відкрити http://localhost:8000
