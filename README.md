# Zrínyi gyakorló

Тренажер для підготовки до математичного конкурсу імені Ілони Зріні (2-8 клас), угорською та українською. Діти обирають клас і розвʼязують задачі. Наприкінці бачать результат і проходять покроковий розбір помилок з Арчі, джек-рассел-терʼєром.

Адреса: https://zrinyi.bodco.pm

## Структура
- `index.html`, `css/app.css`, `js/` (`app.js` екрани, `logic.js` вибір задач і бали, `store.js` localStorage, `i18n.js` тексти HU/UA, `mascot.js` Арчі) - статичний сайт без збірки.
- `data/g2.json` ... `data/g8.json` - задачі за класами.
- `sw.js` - офлайн-кеш. Щоб змусити клієнтів оновитися, підніми версію кешу в цьому файлі.
- Прогрес зберігається лише в localStorage браузера (ключ `zrinyi.v1`). На сторінці прогресу його можна експортувати й імпортувати.

## Формат задачі
```json
{"id":"g5-r2014-07","grade":5,"source":{"type":"real","year":2014,"round":"megyei","no":7},
 "topic":"logic","difficulty":2,"q":{"hu":"...","uk":"..."},"figure":"<svg>...</svg>",
 "options":{"A":"6","B":"9","C":{"hu":"kedd","uk":"вівторок"},"D":"12","E":"16"},"answer":"C",
 "hint":{"hu":"...","uk":"..."},"hints":{"hu":["...","...","..."],"uk":["...","...","..."]},"steps":{"hu":["..."],"uk":["..."]},
 "why":{"A":{"hu":"...","uk":"..."},"B":{},"D":{},"E":{}},"tip":{"hu":"...","uk":"..."}}
```
`level`: необовʼязкове, `"challenge"` для особливо складних задач.
`topic`: numbers, operations, measures, time, geometry, logic, combinatorics, patterns, word. `difficulty`: 1-3. `why` має пояснення для кожного неправильного варіанта.

Реальні задачі взято з бланків конкурсу Zrínyi Ilona Matematikaverseny минулих років (MATEGYE Alapítvány). Решту задач написано для цього сайту.

## Підказки (`hints`)
`hints` має по 3-5 рядків для кожної мови, від найлегшого натяку до детального, але відповідь ніколи не розкривається. Кнопка "Segítség / Підказка" відкриває рівні по одному (бульбашки "1/4", "2/4" ...). Підказки є в тренуванні (швидкому і за темою) та в роботі над помилками, у пробному конкурсі їх немає. Якщо `hints` немає, у роботі над помилками показується лише одна `hint`. У сесії рівні зберігаються в `hints` (макс. відкритий рівень), у `problemStats` це `hintsUsed` і `hintOk` (правильно з підказкою); у результатах біля таких задач значок "💡 N".

## Задачі "challenge" і режим "Виклик"
Задачі з `"level":"challenge"` не потрапляють у швидке тренування, теми та пробний конкурс. Їх показує лише окремий режим "Kihívás / Виклик" (до 5 challenge-задач плюс найважчі задачі складності 3, разом 8, без таймера). Режим зʼявляється, лише якщо в класі є такі задачі. Ці сесії не впливають на відсоток правильних.

## READY_GRADES
У `js/logic.js` константа `READY_GRADES = [2, 5]` визначає, які класи вважаються готовими. Решта плиток на стартовому екрані отримують позначку "Hamarosan / Незабаром", але лишаються клікабельними і ведуть на екран "coming soon" (він показується, коли файл даних порожній). Коли додаєш новий клас, заповни `data/gN.json` і додай номер у `READY_GRADES`. Після змін у файлах підніми `VERSION` у `sw.js` (зараз `zrinyi-v2`).

## Вибір задач
Швидке тренування і тема: 10 задач, цілі за складністю для класів до 3 включно 5/4/1, для решти 4/4/2, порядок строго від легших до важчих (складність, потім `source.no` для реальних, потім випадково). Перевага ще не баченим задачам, без повторів з останніх сесій, реальні та згенеровані задачі приблизно порівну.
